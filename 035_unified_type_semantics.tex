\section{[OUTDATED] Unified Type-Semantics Draft}

\paragraph{Status.}
This file is retained only as a non-normative historical draft. The proposed
relation between an arbitrary type and a general descriptor tuple did not
define a semantics and is withdrawn. It must not be used to select or combine
foundational approaches.

The underlying question is how a type constrains the interpretation of a
term. A comparison must distinguish syntactic expressions, their semantic
values, and judgments asserting that an expression has a type. Keeping
those roles separate makes it possible to study the earlier proposal
without assuming that every alternative uses the same notion of type.

\subsection{Active Type Discipline}
The active line is predicates/formulas-as-types and classes-as-expressions.
Proofs are terms, while class expressions are syntax rather than SML values
containing object-theoretic classes. The earlier identification of every
$(A:\Type)$ with $\top$ remains rejected because it violates uniqueness of the
term--type relation. See \texttt{001\_foundations.tex} and
\texttt{130\_classes\_as\_types.tex}.

\subsection{Independent Alternatives}
The uncertain descriptor calculus, Farmer's PFOL, and conglomerate-valued
semantics retain their own source files and conventions. None supplies a
configuration parameter for the active type system. Any future translation
must separately define its source and target semantics and prove its
metatheoretic properties.
