\section{Cardinals}
\subsection{Axioms}
We will introduce some axioms to make such behaviour provable.\\
\begin{iaxiom}
\[
|\cdot|:V \to \On
\]
Actually, since $|\cdot|$ is a functional symbol, we mean the following:
\[
(x\mapsto |x|):V \to \On
\]
Functional symbol is defined on any class as argument, while $(x\mapsto |x|)$ is defined on sets only. By definition, $(x\mapsto |x|)$ is a class function defined as a class of pairs $\cc{\langle x, |x|\rangle }{ x \any\set}$.
\end{iaxiom}
Actually, we can use the following axiom:
\begin{axiom*}
\[
(x\set)\implies(|x|\in\On)
\]
\end{axiom*}
or even
\begin{axiom*}
\[
(x\set)\implies(|x|\set)
\]
\end{axiom*}
since later we will prove that
\begin{theorem*}
\[
(x\set)\implies(|x|\in\On)
\]
\end{theorem*}

\begin{iaxiom} Sets are hereditary:
\[
(A\subseteq B)\land (B\set) \implies (A\set)
\]
\end{iaxiom}

\subsection{Implementation}
Here $|\cdot|$ is a functional symbol defined as following.
\begin{definition}(cardinality of a class)
\[
|K|\eqdef \On \cap \bigcap \cc{a\in\On}{K\preccurlyeq a}
\]
\end{definition}
\begin{definition}
\[
(X\preccurlyeq Y)
\iff
(\exists f: (f:X\to Y)\land (f \injective))
\]
\end{definition}
The intended behaviour of this definition is to have cardinality of argument if the argument of a functional symbol is a set, and $\On$ if the argument is a proper class.\\

\section{Theorems related to Limitation of Size}
%\subsection{Foundations and large cardinals}%

The goal is to prove axiom of limitation of size using the small amount of usual axioms and simple definitions.\\

\begin{iaxiom}
Axiom of limitation of size:
\[
(K\in V)
\iff
(|K| < |V|)
\]
\end{iaxiom}



Some equivalent(in normal context) statements:
\[
(K\in V)
\iff
(|K| \subsetneq |V|)
\]
\[
(K\in V)
\iff
(|K| \neq |V|)
\]
because $|V|=\On$.


\subsection{Proof of Limitation of Size via other axioms}
We want to prove the following statement:
\[
(K \in V) \iff (|K| \neq |V|)
\]

Firstly, we will prove some lemmas:



\begin{lemma}(1st part of the statement, from left to right)
\[
(K \in V) \implies (|K| \neq |V|)
\]
\end{lemma}
\Proof
Assume $(K \in V)$.\\
By our axiom, since $(K \in V)$ we have $(|K| \in \On)$.\\
By previous lemmas we have $|V|=\On$ and $\On\notin\On$.\\
From these three statements we deduce that $|K| \neq |V|$.\\
