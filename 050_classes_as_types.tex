\subsubsection{$\Sigma$-types}

In type theory, the formatin rule for a $\Sigma$-type is
\begin{prooftree}
\AxiomC{
$(A:\Type)$\quad\quad$(x:A\vdash B(x):\Type)$
}
\RightLabel{$\Pi$-form}
\UnaryInfC{$
\vdash \Sigma_{(x:A)}B(x):\Type  
$}
\end{prooftree}

Assume that $(F\family)$.

\begin{definition}(Dependent sum)
\[
\Sigma F = \mbox{E}^{-1} \circ F
\]
\end{definition}
