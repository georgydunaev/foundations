1. **Definable Power Set Def(X)**:

   - For hereditarily finite sets and finite transitive stages, every subset is definable using equality with parameters: phi(x) iff (x = p1 or ... or x = pk).
   - Def(X) is transitive whenever X is transitive.

2. **Constructible Hierarchy L_alpha and Constructible Universe L**:
   - Transfinite definition: L_0 = empty, L_{alpha+1} = Def(L_alpha), and L_lambda = Union_{beta < lambda} L_beta for limit ordinals lambda.
   - The proper class L = Union_{alpha in Ord} L_alpha is the smallest inner model of ZF containing all ordinals.
   - In MKTD, the Axiom of Constructibility V = L asserts that every set x is an element of L_alpha for some ordinal alpha.

3. **Godel Condensation Lemma**:
   - Let lambda be a limit ordinal (or uncountable cardinal) and M an elementary submodel of L_lambda (M prec L_lambda).
   - Since L_lambda is extensional and well-founded, M is extensional and well-founded.
   - By Mostowski's Collapsing Theorem, there exists a unique transitive set N and isomorphism pi : M isomorphic to N.
   - Godel's Condensation Lemma establishes that N = L_alpha for some ordinal alpha with |alpha| <= |M|.

4. **Constructible Well-Ordering and L |= AC**:
   - In L, formulas and parameters are generated by a canonical, definable well-ordering <_L.
   - For any constructible set x, its definable subsets are ordered by their minimal defining formula codes and parameters.
   - This yields a global definable well-ordering of L, proving L |= AC (and MKTD |= AC in L).

5. **L |= GCH**:
   - For an infinite cardinal kappa, any constructible subset X subset of kappa belongs to L.
   - By the Downward Lowenheim-Skolem theorem and Condensation Lemma, any such X is captured in an elementary submodel M prec L_lambda of cardinality kappa containing kappa as a subset.
   - The Mostowski collapse collapses M to L_alpha with |alpha| <= kappa, meaning alpha < kappa^+.
   - Hence Powerset(kappa) cap L is a subset of L_{kappa^+}, yielding 2^kappa <= |L_{kappa^+}| = kappa^+.
   - Combined with Cantor's Theorem 2^kappa >= kappa^+, this proves 2^kappa = kappa^+ in L.
