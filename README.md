# Foundations of Mathematics

## Chapter and File Map

### Core Foundations
- **000_preamble.tex**: LaTeX preamble for the Foundations of Mathematics document.
- **001_foundations.tex**: Primary active kernel approach using Classical 2-valued Morse-Kelley / NBG class theory with Dunaev Tagged Ordered Pairs.
- **010_logic.tex**: Logical framework including conglomerate terms of all classes.
- **020_descriptors.tex**: Alternative approach using Hilbert's 3-operator descriptors with Kleene U value.
- **030_alternative_semantics.tex**: [OUTDATED] Historical variant of Conglomerate subset semantics.

### Formalizations
- **presentation.ML**: Presentation of Class-Theoretic Foundations based on Morse-Kelley class theory and Tarski's axiom.
- **Coq/positive_foundations.v**: Coq formalization of positive foundations, including inductive definitions of ensembles and ordered pairs.

### Additional Resources
- **APPROACHES_INVENTORY.md**: Inventory of different approaches to the foundations of mathematics.
- **LATEX_AUDIT_REPORT.md**: Report on the LaTeX documentation and its status.
- **PRESENTATION_ML_GUIDE.md**: Guide for the presentation.ML file.
